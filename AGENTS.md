# Nail Tracker

A free, private, offline pay tracker for nail technicians. React, TypeScript, Vite, Dexie. No server.

If you were given a task, read `tasks/nail-tracker/README.md` and then your one brief in `tasks/nail-tracker/`. Those rules apply to you. The short version:

- One task per session. Commit to the branch your brief names. Do not push, and do not run `gh`.
- Do not edit `tasks/`. Add no packages unless your brief says so.
- Money is whole cents. Never use floats for money.
- Finish with `pnpm gate` passing. Browser tests run with `pnpm exec playwright test --workers=2`, never more workers.
- Stuck on the same error after 3 tries? Stop and report BLOCKED.

The product document is `docs/product-spec.md`.
